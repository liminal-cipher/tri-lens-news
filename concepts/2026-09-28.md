## agent harness

**한 줄 정의:** LLM을 감싸서 프롬프트 전달과 실행 제어 흐름, 오케스트레이션을 담당하는 구동 구조를 의미합니다.

**왜 지금:** 최근 표본에서 에이전트 성능 평가 시 백본 모델만큼 하네스 구조의 영향력이 크게 부각되고, 하네스 제어 구조 자체를 자율적으로 개선하려는 연구가 나타나고 있기 때문입니다.

**실무에서:** 에이전트 시스템 개발이나 벤치마크 평가 시 성능 및 비용 병목이 모델 자체의 한계인지 제어 구조(하네스)의 문제인지 구분할 때 유용합니다.

## contrastive language model

**한 줄 정의:** 텍스트 문장을 직접 생성하는 대신 상태와 행동의 벡터를 비교하여 최적의 행동 선택지나 정답 후보의 순위를 골라내는 언어 모델입니다.

**왜 지금:** 최근 표본에서 추론 지연 시간을 낮추기 위해 가중치가 고정된 LLM에 프로젝션 헤드를 결합해 행동 선택 및 검증자(verifier) 역할을 맡기는 방식이 제시되었기 때문입니다.

**실무에서:** 저지연 에이전트 시스템이나 검증 단계를 설계할 때 텍스트 직접 생성 방식과 생성된 후보군을 골라내는 정렬/선택 방식을 구분해 적용할 때 유용합니다.
