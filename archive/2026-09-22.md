## 1. AI coding has made CI a bottleneck, so we reworked ours to keep up

원문: <https://linear.app/now/ci-bottleneck-reworked> (Hacker News)

🌐 Everyone
인공지능이 코드를 만들어내는 속도가 급격히 빨라지면서 새로 작성된 프로그램을 검사하고 승인하는 과정에서 병목 현상이 발생했습니다.
검사 도중 무의미하게 대기하는 순서를 없애고 일처리 기계를 고성능으로 바꿔 검사 대기 시간과 자원 소모를 크게 줄였습니다.

💻 Developers
CI(지속적 통합, 작성한 코드를 자동으로 검증하고 반영하는 시스템) 병목을 풀기 위해 외부 고성능 runner로 이전하고 type graph 없이 AST 기반으로 정적 분석을 수행하는 Oxlint를 적용했습니다.
네트워크 불안정에 대응하는 재시도 로직을 직접 구축해야 하는 관리 부담이 늘어나며, 타입 정보 기반의 정밀한 린팅 규칙을 일부분 포기하는 대가를 치러야 합니다.

🔬 Researchers
성능 개선 수치에서 고성능 인프라 교체와 AST 기반 정적 분석 전환이 각각 기여한 독립적 효과가 엄밀히 분리되지 않았습니다.
에이전트의 코드 생성량이 지금보다 수십 배 늘어날 때 타입 검증 없는 구문 분석만으로 에러를 사전 차단할 수 있는 한계점이 연구 과제로 남습니다.

## 2. 샤오미, MiMo-V2.6 공개 - 강화학습 과정을 공개한 멀티모달 모델

원문: <https://news.hada.io/topic?id=34085> (GeekNews)

🌐 Everyone
샤오미가 AI가 혼자서 문제를 풀며 실력을 키우는 학습 과정과 내부 설계를 모두에게 투명하게 풀어놓았습니다. 그 결과 컴퓨터 조작부터 3D 그래픽과 음악 제작, 과학 연구 보조까지 인간의 복잡한 업무를 대신 수행하는 능력이 대폭 향상되었습니다.

💻 Developers
Mixture of Experts(MoE, 필요한 전문가 영역만 활성화하는 방식) 구조를 채택해 100만 토큰의 컨텍스트를 유지하면서도 inference(추론) 효율성을 크게 높였습니다. open weights로 제공되어 자체 인프라 구축이 가능하지만, 20배 빠른 속도를 내는 모드는 API 호출 비용이 10배로 상승하므로 서비스 요금 설계를 세심하게 계산해야 합니다.

🔬 Researchers
단일 RL(강화학습) 파이프라인에서 서로 다른 도구와 실행 환경을 섞어 학습시켰을 때 발생하는 cross-domain transfer의 정확한 기여도가 정량적으로 고립되지 않았습니다. 또한 적대적 평가와 검증기 교차 확인 방식이 다단계 에이전트 환경에서 reward hacking(보상 체계의 허점을 악용하는 행위)을 근본적으로 차단했는지는 추가적인 ablation study가 필요합니다.

## 3. Can MiniMax-H3 Reason About the Physical World? An Evaluation of Omni-Modal Generative Model

원문: <https://arxiv.org/abs/2609.18323> (Hugging Face Papers)

🌐 Everyone
글자, 사진, 소리, 영상을 동시에 다루는 인공지능이 조각난 정보만으로 현실 세계의 물리 현상을 얼마나 잘 추론하는지 평가하는 시험대가 만들어졌습니다. 영상의 다음 장면을 파악하는 능력은 준수했지만, 소리 정보를 바탕으로 물체의 상황을 맞히는 능력은 여전히 많이 부족했습니다.

💻 Developers
MiniMax-H3는 shared latent framework(여러 신호를 공통 공간에서 함께 처리하는 구조)로 omni-modal 입력을 추론하지만, 모달리티 결합 방식에 따라 성능 불균형이 크게 나타납니다. 실시간 시스템에 적용할 때 연산량과 딜레이가 증가하는 대가를 치르고도 audio-video 연동 시 정확도가 급격히 떨어지는 문제가 발생합니다.

🔬 Researchers
audio-based disambiguation reasoning의 저조한 성과가 모달리티 간 정렬 실패 때문인지 단일 오디오 인코더의 표상 한계 때문인지가 명확히 분리되지 않았습니다. 통합 표현 공간이 실제 물리적 상태 추론에 직접 기여하는지를 구증하려면 모달리티 소거 조건별 ablation 연구가 추가로 필요합니다.
