## 2. IBM Bob - IBM의 AI 코딩 에이전트

원문: <https://news.hada.io/topic?id=33242> (GeekNews)

🌐 Everyone
새로운 프로그램을 처음부터 만드는 것보다 오래전에 작성되어 복잡하고 낡은 기업용 전산 시스템을 AI가 분석해서 최신 방식으로 안전하게 고쳐줍니다.
수십 년간 수정하기 두려워 방치했던 은행이나 기관의 내부 프로그램을 인간의 감독하에 차근차근 바꿀 수 있게 됩니다.

💻 Developers
Ask, Plan, Agent 모드로 작업을 분율하고 sub-agent를 활용해 대화 맥락이 불필요하게 커지는 것을 막으며, Model Context Protocol(AI 모델과 사내 시스템을 연결하는 규격)과 Agent Client Protocol로 여러 개발 환경에 연결합니다.
다만 legacy 코드베이스를 마이그레이션할 때 대화와 문맥 파악이 길어질수록 텍스트 처리량 기반의 Bobcoin 비용이 급증하고, 규칙 기반 변환 도구와 AI의 판단이 얽힐 때 빌드 오류 처리가 복잡해지는 대가가 따릅니다.

🔬 Researchers
정적 분석 도구와 OpenRewrite 같은 규칙 기반 변환기, 그리고 LLM 추론을 결합한 유휴 워크플로에서 시스템 단위 오류가 AI 교정 단계로 넘어갈 때 발생하는 오차 전파율이 명확히 측정되지 않았습니다.
단일 추론의 context window(모델이 한 번에 기억하는 입력 길이) 한계를 극복하기 위해 도입한 sub-agent 구조가 복잡한 의존성 그래프를 분할할 때 문맥 손실이나 환각을 얼마나 억제하는지 입증하려면 별도의 ablation(요소 제거 실험) 연구가 필요합니다.

## 3. Compile by Training: Turning Natural-Language Specifications into Local Neural Functions

원문: <https://arxiv.org/abs/2609.04199> (Hugging Face Papers)

🌐 Everyone
거대한 인공지능에게 매번 돈을 주고 물어보는 대신 원하는 기능을 말로 설명하면 작고 빠른 맞춤형 프로그램으로 변환해 주는 기술이 나왔습니다.
초기 제작에 1분 정도의 시간이 소요되지만 한번 만들어두면 인터넷 연결이나 추가 비용 없이 기기 내부에서 바로 작동합니다.

💻 Developers
대형 teacher model이 생성한 데이터를 기반으로 소형 경량 모델용 adapter(작은 보조 신경망)를 학습시켜 일반 소프트웨어처럼 버전 관리와 연동이 가능한 형태로 구축합니다.
FuzzyBench-Hard 기준 83.6%의 높은 semantic accuracy(의미적 정확도)를 확보하는 대신 컴파일 단계에서 약 1분의 시간이 추가로 발생하는 대가를 치릅니다.

🔬 Researchers
teacher model이 생성하는 synthetic data(합성 데이터)의 신뢰도와 다양성이 소형 신경망의 최종 정밀도에 미치는 독립적 영향이 아직 완전히 분리되어 검증되지 않았습니다.
요구 명세의 난이도가 올라갈 때 짧은 학습 과정만으로 catastrophic forgetting(이전 지식을 잊는 현상) 없이 새로운 추론 패턴을 완전히 흡수할 수 있는지에 관한 한계 규명이 필요합니다.
