## 1. How OpenAI Used Its Own LLMs to Design Its Jalapeño Chip

원문: <https://spectrum.ieee.org/llms-for-chip-design> (Hacker News)

🌐 Everyone
인공지능 기업이 스스로 개발한 인공지능의 대답 속도를 3배 이상 높여주는 맞춤형 반도체를 자체 제작했습니다.
사람 대신 인공지능 프로그램을 활용하여 반도체의 구조를 설계하고 내부 작동 프로그램을 조정하는 기간을 크게 줄였습니다.

💻 Developers
high-level synthesis(고수준 프로그래밍 언어로 회로를 설계하는 기법) 도구인 XLS 기반으로 C++이나 DSLX 코드를 Verilog로 변환하는 작업을 LLM에 맡겨 RTL 개발 기간을 압축했습니다.
칩 출고 이후에도 LLM이 kernel(반도체용 연산 프로그램) 코드를 자동 최적화해 성능을 끌어올렸으나, 물리적인 회로 배치와 제조 단계에서는 외부 파트너십에 의존해야 하는 제약이 남습니다.

🔬 Researchers
개발 기간 단축이 LLM의 로직 생성 능력 발전 덕분인지 아니면 소수 인원이 제어하기 쉬운 프론트엔드 추상화 도구를 선택한 결과인지 변수가 격리되지 않았습니다.
2,048개의 칩을 묶은 pod(여러 칩을 묶은 서버 단위) 구조에서 발생할 인터커넥트 병목과 대규모 실제 인퍼런스 워크로드에서의 실질 전력 효율은 추후 검증이 필요합니다.

## 2. Cache-to-Cache: Direct Semantic Communication Between LLMs (2025)

원문: <https://arxiv.org/abs/2510.03215> (Hacker News)

🌐 Everyone
여러 인공지능 모델이 함께 일할 때 글자를 매개로 대화하지 않고 내부 정보 형태 그대로 교환하는 기술이 나왔습니다. 답변을 글자로 만들어 주고받는 과정을 건너뛰면서 대화 응답 속도가 두 배 이상 빨라지고 답변 정확도도 함께 올라갑니다.

💻 Developers
텍스트 생성 과정 없이 KV-Cache(이전 대화의 중간 연산 상태를 저장한 정보)를 신경망으로 투영하여 타겟 모델에 직접 전달하는 C2C 구조입니다. 토큰 생성 지연시간을 대폭 줄일 수 있지만 모델 간 캐시 차원을 맞추는 투영 네트워크와 layer 선별용 gating mechanism을 별도로 훈련시키고 관리해야 합니다.

🔬 Researchers
C2C가 연산 속도를 개선하는 과정에서 전달되는 KV-Cache가 깊은 semantic을 온전히 전달하는지 아니면 단순히 특정 레이어의 표면적 표현만 정렬하는지 명확히 분리하여 검증하지 못했습니다. 아키텍처나 파라미터 규모 차이가 극심한 LLM 사이에서도 gating mechanism이 안정적으로 동작하는지에 대한 일반화 연구가 과제로 남아있습니다.

## 3. LimiX-2: A Contextual Mechanism Network Towards General Structured-Data Intelligence

원문: <https://arxiv.org/abs/2609.17488> (Hugging Face Papers)

🌐 Everyone
표 형태의 데이터를 다룰 때 결과값 하나만 겨우 맞추던 AI가 데이터 전체의 생성 규칙과 관계를 한꺼번에 이해하도록 진화했습니다. 복잡한 금융이나 의료 데이터에서 예측 정확도가 높아지고 데이터 간의 진짜 원인 관계까지 파악할 수 있게 됩니다.

💻 Developers
p(y|x, D_{context}) 기반의 기존 tabular PFNs(전달받은 문맥으로 표 데이터를 예측하는 모델)와 달리 Contextual Mechanism Networks를 통해 p(x, y|D_{context})의 결합 분포를 학습합니다. SCMs(데이터 생성 구조를 정의하는 인과 모델) 기반 합성 데이터로 pretraining하여 causal skeleton을 복원하지만, 문맥 기반 연산이 늘어나 추론 시 연산 부하가 증가합니다.

🔬 Researchers
TabArena 및 TALENT 등에서의 성능 향상이 SCMs 합성 데이터의 다양성에 기인한 것인지 Contextual Mechanism Networks 구조 자체의 유연성 때문인지가 명확히 분리되지 않았습니다. feature attention이 포착한 인과 구조가 실세계 데이터의 관측 편향이나 교란 변수 환경에서도 유지되는지 검증하는 ablation 연구가 필요합니다.
