## 2. OpenAI GPT–6 Astra breaks Enigma message that has resisted solution since 2005

원문: <https://www.cryptocellar.org/bgac/the-mvueh-break.html> (Hacker News)

🌐 Everyone
인공지능이 80년 전 작성된 독일군의 미해독 암호를 사람의 구체적인 지시 없이 스스로 외부 사료까지 찾아보며 풀어냈습니다. 문제를 해결하는 데 필요한 계산 프로그램을 직접 작성하고 가설을 검증하며 수개월이 걸릴 작업을 단 이틀 만에 완료했습니다.

💻 Developers
GPT-6 Astra는 crib(암호문에서 유추되는 평문 단어)을 발굴한 뒤 C++ 및 Python 시뮬레이터를 직접 생성해 구동하는 agentic workflow를 선보였습니다. 이처럼 자율적으로 외부 데이터베이스에 접근하여 자원을 탐색하는 시스템은 접근 권한 제어와 행동 제약 설계를 대폭 강화해야 하는 대가가 따릅니다.

🔬 Researchers
이 암호 해독이 고도화된 generalized cryptanalysis 능력 덕분인지, 혹은 내부 사료가 포함된 data contamination(학습 데이터 오염)의 결과인지는 실행 로그를 추가 분석해야 갈라낼 수 있습니다. 또한 모델이 제시한 외부 문서 참조 번호의 출처가 실시간 retrieval에 의한 것인지 단순 hallucination의 우연한 적중인지도 규명 대상입니다.

## 3. RRSI: Regularized Recursive Self-Improvement of Agent Harnesses

원문: <https://arxiv.org/abs/2609.24972> (Hugging Face Papers)

🌐 Everyone
인공지능이 스스로 작동 방식이나 명령어를 수정하며 성능을 높이는 과정에서 평가용 시험문제만 달달 외워버리는 문제가 발생했습니다.
이 연구는 인공지능의 자율 수정 규칙에 엄격한 제약을 두어 처음 접하는 실제 업무에서도 안정적인 해결 능력을 유지하도록 만듭니다.

💻 Developers
agent harness(LLM을 감싸는 프롬프트 및 제어 흐름 구조)를 개조하는 recursive self-improvement(RSI)의 과적합을 막기 위해, 수정 예산을 제한하고 critic과 pruner를 결합한 RRSI를 적용합니다.
추론에 쓰이는 policy token 소모량을 30% 줄이면서 외연적 성능을 높이지만, 최적화를 위한 탐색 단계에서 다수의 검증 호출과 파라미터 조율 비용이 지출됩니다.

🔬 Researchers
OOD(out-of-distribution) 성능 상승이 고정된 백본 모델 특성에 종속된 것인지 아니면 모델 스케일 전반에 일반화되는지 분리되어 검증되지 않았습니다.
아울러 탐색 공간이 유기적으로 확장될 때 critic이 유효한 매커니즘을 소음으로 오인해 과도하게 잘라내지 않는지 그 한계선도 지속적인 연구 과제입니다.
