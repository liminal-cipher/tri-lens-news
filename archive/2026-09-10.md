## 1. Shopify acquires Tailwind

원문: <https://tailwindcss.com/blog/tailwind-is-joining-shopify> (Hacker News)

🌐 Everyone

## 3. NeoHorse-1: Towards Recursive Self-Improvement via Agentic Post-Training with Routing Harness

원문: <https://arxiv.org/abs/2609.08183> (Hugging Face Papers)

🌐 Everyone
AI가 사람의 요청을 처리할 때 어떤 능력이 필요한지 스스로 기록하고 분석하여 다시 학습에 활용하는 기술이 등장했습니다. 이를 통해 작은 크기의 AI도 큰 AI 못지않게 복잡한 작업을 능숙하게 해결할 수 있게 됩니다.

💻 Developers
agentic post-training과 routing harness를 결합하여 사용자 요청의 맥락과 도구 호출을 기록하고 routing-guided on-policy distillation(선생님 모델이 실시간으로 학생 모델의 생성을 지도하는 학습 기법)으로 전달합니다. 다만 heterogeneous model pool을 동시에 운용하고 subscene-level labeling 같은 정교한 데이터 검증 라인을 갖춰야 하므로 파이프라인 유지 비용이 커집니다.

🔬 Researchers
성능 향상이 curriculum SFT의 단계별 설계 때문인지 세밀한 semantic evaluation 필터링의 영향인지 구체적인 ablation(구성 요소를 하나씩 제거하며 효과를 파악하는 실험) 결과가 명확히 분리되지 않았습니다. 반복적인 recursive self-improvement 과정에서 나타날 수 있는 모델의 편향 누적이나 성능 포화 시점을 다회차 실험으로 검증하는 과제가 남아 있습니다.
