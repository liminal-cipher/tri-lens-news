## 3. VoiceMem: Streaming Dual-Brain Memory for Real-Time Interaction

원문: <https://arxiv.org/abs/2608.26005> (Hugging Face Papers)

🌐 Everyone
음성으로 대화하는 인공지능이 사용자의 대화 내용뿐만 아니라 감정과 성격까지 실시간으로 기억하며 대화를 이어갑니다.
대화가 길어져도 끊김 없이 사용자를 이해하고 기억해 한층 자연스럽고 개인화된 음성 대화를 제공합니다.

💻 Developers
실시간 대화 모델에 정보 전달용 좌뇌와 감정·페르소나용 우뇌로 메모리를 분리한 dual-brain 구조를 적용했습니다.
134 ms의 검색 지연 시간을 확보해 VAD(Voice Activity Detection, 음성 활동 감지) 구간 안에서 동작하며 지연을 없앴지만, 두 메모리 스트림을 동기화하고 관리하는 인프라 구축 부담이 따릅니다.

🔬 Researchers
정보 검색 정확도와 감정 추적 성능의 상승이 dual-node 구조 자체에서 오는지, 개별 메모리 백엔드의 성능 차이에서 온 것인지 명확히 갈라내지 못했습니다.
잡음이 섞인 음성 환경이나 극단적인 장기 대화 상황에서 두 메모리 노드가 오염되지 않고 유지되는지에 대한 ablation이 더 필요합니다.
