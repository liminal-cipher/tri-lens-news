## 1. Meta가 AI 인프라의 매출 기여도를 측정한 방법

원문: <https://news.hada.io/topic?id=33720> (GeekNews)

🌐 Everyone
대형 IT 기업들은 AI 서비스를 구동하는 내부 시스템에 천문학적인 자금을 투자하지만, 그중 어떤 기술이 실제 매출을 늘려주는지 정확히 파악하기 어려웠습니다.
메타는 단순히 인기 있는 시스템이 아니라 실제 수입 증대에 직접 기여한 알짜배기 개발 도구를 가려내는 분석 방식을 도입해 향후 AI 기술 투자 우선순위를 완전히 교정했습니다.

💻 Developers
A/B testing이 불가능한 shared AI infrastructure의 매출 기여도를 재기 위해, 모델 출시 데이터에 GPU 할당량, 팀 규모, 계절성, 모델 복잡도를 통제한 selection-on-observables(관측 변수를 통한 편향 통제) 기법을 적용했습니다.
단순 사용량이 높던 기반 계층의 착시는 selection bias(선택 편향)였음을 밝혀내며 학습 확장성 플랫폼에 예산을 재배정했지만, 개별 배포 단위의 정확한 인프라 사용 로그 수집과 더 넓은 신뢰구간을 받아들여야 합니다.

🔬 Researchers
관측 가능한 covariates(인과 분석 시 통제하는 교란 변수)를 정밀하게 통제했음에도, 개별 엔지니어의 정성적 역량이나 팀 고유의 개발 문화 같은 미관측 교란 요인이 완벽히 소거되었는지는 입증하기 어렵습니다.
아울러 여러 개발 플랫폼을 동시에 도입할 때 나타나는 다중 처치 간 상호작용과 장기적인 기술 이월 효과를 명확한 causal inference(인과 추정)로 갈라내는 모형 설정은 미완의 과제로 남아있습니다.

## 2. Pinterest 임베딩 검색 플랫폼의 진화

원문: <https://news.hada.io/topic?id=33719> (GeekNews)

🌐 Everyone
Pinterest는 사용자의 검색어와 추천 이미지를 찾아주는 내부 시스템을 개편하여 운영 비용을 크게 낮췄습니다.
데이터 크기를 효율적으로 줄이고 메모리 대신 저렴한 저장장치를 활용하는 기술을 도입해 추천 정확도를 유지하면서도 서버 자원을 대폭 절약했습니다.

💻 Developers
Scalar Quantization과 Product Quantization으로 벡터를 압축하고 SPANN 알고리즘을 도입해 RAM 의존도를 줄인 NVMe SSD 서빙 환경을 구축했습니다.
이 과정에서 디코딩 오버헤드를 막기 위해 SIMD(단일 명령어로 다수 데이터를 처리하는 기술) 최적화를 적용해야 하며 인덱스 압축에 따른 Recall 하락을 수용 가능한 범위 내로 관리해야 합니다.

🔬 Researchers
Late Interaction(후기 상호작용) 기반 다중 임베딩 검색으로 세부 의미 표현력을 끌어올릴 때 늘어나는 쿼리 연산량과 SSD I/O 병목의 상관관계는 추가적인 정량 분석이 필요합니다.
향후 GPU 검색 플랫폼으로 전환하는 과정에서 수백억 개 인덱스의 꼬리 지연 시간을 제어하며 메모리 대역폭 한계를 극복할 신규 알고리듬 개척이 핵심 연구 과제입니다.

## 3. SpatialBlock: Enhancing Spatial Intelligence in LVLMs via Synthetic Block-Stacking Problem

원문: <https://arxiv.org/abs/2609.07064> (Hugging Face Papers)

🌐 Everyone
2D 사진 속 물체들의 위치나 입체적 관계를 제대로 파악하지 못하던 인공지능이 블록 쌓기 문제를 학습하며 공간을 이해하는 능력을 키웠습니다. 이제 비싼 실제 사진 데이터를 새로 모으지 않고도 가상 데이터 학습만으로 현실의 입체 구조와 시점을 더 정확하게 알아봅니다.

💻 Developers
SpatialBlock-15k 데이터셋으로 LVLM(Large Vision-Language Model, 대형 비전-언어 모델)의 spatial intelligence를 미세조정하여 3D-to-2D projection 능력을 강화할 수 있습니다. 수작업 geometric annotation(기하학적 주석) 비용을 대폭 줄일 수 있는 대신, 합성 데이터 학습이 유발하는 domain shift 문제로 실무 환경 적용 시 예측하기 어려운 오작동 가능성이 남아 있습니다.

🔬 Researchers
실세계 3D 공간으로의 real-world generalization 성능 향상이 3D-to-2D projection 질문 구조의 효과인지 anchor 역할을 하는 색상 조절 덕분인지 명확히 갈라지지 않았습니다. 두 요인의 개별 기여도를 분리해 검증하려면 관측 가림 정도와 블록 개수를 단계별로 통제한 ablation study가 필요합니다.
