## 1. Llama.cpp on a jailbroken PS5: run any GGUF model natively on the console

원문: <https://github.com/cobanov/PS5LM> (Hacker News)

🌐 Everyone
PS5에 설치된 앱이 집 안 모든 기기에서 AI 대화를 가능하게 하는 가정용 AI 서버 역할을 합니다. 별도 서버나 클라우드 없이 TV 화면에서도 직접 질문하고 답을 받을 수 있어 개인 데이터가 외부로 나가지 않습니다.

💻 Developers
가정용 AI 서버는 jailbroken PS5에 GGUF 형식 모델을 로드하고, llama.cpp의 Vulkan 백엔드를 이용해 콘솔의 RDNA 2 GPU에서 직접 추론을 수행하여 OpenAI와 Anthropic 호환 API를 통해 네트워크상의 장치에 서비스를 제공합니다. 이 기능을 사용하려면 firmware 7.00‑13.60, kstuff-lite·etaHEN·ShadowMountPlus 등 필수 패치와 11 GB 이하 모델을 저장할 내부 또는 외부 저장소가 필요하며, 메모리와 토큰 처리량에 따라 응답 속도가 제한됩니다.

🔬 Researchers
가정용 AI 서버와 그 기반인 llama.cpp Vulkan 포팅은 현재 PS5의 메모리와 전력 제한 때문에 대규모 모델(예: 27 B 파라미터)에서 토큰당 처리 속도가 크게 감소하고, 장시간 사용 시 열 관리가 미흡하다는 점이 남아 있습니다. 또한 비공식적인 펌웨어 변조 환경에서 실행되므로 악성 코드 침투 위험과 모델 라이선스 준수 문제를 체계적으로 평가하는 연구가 아직 진행 중입니다.

## 2. Apple ML Research: Muse Spark Open with MLX on Mac Studio

원문: <https://machinelearning.apple.com/research/mlx-distributed-inference> (Hacker News)

🌐 Everyone
Apple이 발표한 MLX 덕분에 일반 사용자도 맥 스튜디오에서 거대한 언어 모델을 직접 실행해 답변을 만들 수 있게 되었습니다. 이렇게 로컬에서 AI를 돌리면 인터넷 연결 없이도 개인 데이터가 외부로 새어나가지 않아 프라이버시가 보호되고, 실시간으로 사람보다 빠른 텍스트 생성이 가능합니다.  

💻 Developers
Local AI Studio는 MLX 프레임워크와 Apple Silicon의 unified memory 구조를 활용해 모델 파라미터를 메모리에 그대로 두고 GPU Neural Accelerator가 행렬 연산을 가속함으로써 동작합니다. 이 방식은 RDMA (Remote Direct Memory Access) 기반 Thunderbolt 5 연결을 통해 여러 맥 스튜디오를 파이프라인으로 묶어 확장할 수 있지만, 각 장비의 메모리와 전력 소모를 고려해 비용‑효율성을 따져야 합니다.  

🔬 Researchers
Local AI Studio와 그 구현 방식에 비추어 보면, 현재 MoE 모델의 4‑bit quantization(양자화)이 정확도에 미치는 영향과 대규모 파이프라인에서 발생하는 지연 시간 최소화 방안이 충분히 검증되지 않았습니다. 이러한 점을 해결하려면 다양한 정밀도 설정과 네트워크 토폴로지를 실험해 성능‑정밀도 트레이드오프를 체계적으로 분석하는 연구가 필요합니다.

## 3. Waypoint-OPD: Transferring RL-Induced Policy Shifts via Gated On-Policy Distillation

원문: <https://arxiv.org/abs/2610.21601> (Hugging Face Papers)

🌐 Everyone  
새로 제안된 방법은 AI가 문제를 푸는 과정에서 중간 단계의 변화를 살펴보며 학습하도록 돕습니다. 이렇게 하면 수학과 코딩 같은 복잡한 추론 작업에서 모델이 더 정확하고 안정적으로 답을 내놓게 됩니다.  

💻 Developers  
Waypoint-OPD는 초기와 최종 교사 모델의 policy shift (강화학습 후 행동 확률 변화)를 같은 입력 앞부분에서 비교해 방향이 일치할 때만 최종 변화를 학생 모델에 적용합니다. 이 과정은 한 번의 추가 교사 스코어링(pass)만 필요해 연산 비용이 크게 늘어나지 않으며, 기존 엔드포인트만 이용한 distillation (교사 모델의 지식을 학생 모델에 전달하는 과정)보다 높은 성능을 제공합니다.  

🔬 Researchers  
현재는 어느 시점의 교사 체크포인트를 선택해야 가장 효과적인지와, 대규모 모델에 적용했을 때 발생할 수 있는 메모리·시간 병목이 명확히 규명되지 않았습니다. 또한 초기와 최종 정책 변화가 상충할 때 발생하는 학습 신호의 해석과, 이러한 경우에 대한 자동 조정 메커니즘 개발이 남은 과제로 남아 있습니다.
