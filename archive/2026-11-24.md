## 1. Lowering Perplexity Without Scaling

원문: <https://micjm.com/blog/lowering-perplexity-without-scaling/> (Hacker News)

🌐 Everyone  
OpenAI가 공개한 차트는 모델이 코드 텍스트를 예측할 때 퍼플렉시티가 크게 낮아졌다고 보여줍니다. 하지만 이는 모델이 일반적인 언어보다 코드에 특화되었음을 의미하며, 전체 지능을 평가하는 지표로 바로 쓰기엔 한계가 있습니다.  

💻 Developers  
‘코드 전용 퍼플렉시티 감소’는 학습 데이터 중 코드 비중을 75%까지 높인 결과이며, 이때 코드에 대한 예측 정확도는 상승하지만 일반 텍스트에 대한 정확도는 급격히 떨어집니다. 따라서 코드 자동 완성 등 코드 중심 서비스에는 유리하지만, 다목적 언어 모델로 사용할 경우 성능 저하와 사용자 경험 악화를 감수해야 합니다.  

🔬 Researchers  
‘코드 전용 퍼플렉시티 감소’ 현상이 모델 규모와 무관하게 데이터 구성만으로도 크게 변할 수 있다는 점은 아직 충분히 규명되지 않았습니다. 다양한 도메인에 대한 독립적인 평가와 데이터 비율을 조절한 ablation 연구가 필요합니다.

## 2. NariQ: BF16 수준의 Qwen3.8-27B를 10GB 파일에 담다

원문: <https://news.hada.io/topic?id=37749&utm_source=geeknews&utm_medium=rss&utm_campaign=news> (GeekNews)

🌐 Everyone  
대형 언어 모델인 Qwen3.8‑27B가 10GB 파일로 압축돼서 일반 노트북에서도 실행할 수 있게 되었습니다. 하지만 압축된 모델은 고성능 GPU에 비해 실행 속도가 느려서, 실시간 코딩 보조 같은 빠른 응답이 필요한 상황에서는 한계가 있습니다.  

💻 Developers  
NariQ quantization은 가중치를 회전시켜 가우스 잡음 형태로 만든 뒤, 최적의 비트 조합을 찾아 2‑bit~3‑bit 수준으로 인코딩하는 방식으로, BF16 품질을 유지하면서 파일 크기를 절반 이하로 감소시킵니다. 이 방법은 Metal API를 이용한 Mac 환경에서 동작하지만, KV cache와 activation quantization이 추가적인 연산을 요구해 토큰당 처리 속도가 GPU 대비 낮아지는 비용을 감수해야 합니다.  

🔬 Researchers  
현재 NariQ가 손실한 정보가 주로 중복된 지식인지, 혹은 미세한 추론 능력에 영향을 주는지 정확히 구분되지 않아 실제 적용 범위를 판단하기 어렵습니다. 또한 평가 환경 차이가 성능 차이를 크게 만들 수 있다는 점이 밝혀졌으므로, 다양한 워크로드와 데이터 분포에서 일관된 벤치마크를 구축하는 연구가 필요합니다.

## 3. cmHC: Balancing Stream Mixing in Hyper-Connections via Geometric Contraction

원문: <https://arxiv.org/abs/2611.27193> (Hugging Face Papers)

🌐 Everyone
새로운 방법은 AI 모델이 여러 정보 흐름을 균형 있게 섞도록 하여 어느 하나가 지나치게 지배하거나 완전히 섞이지 않게 방지합니다. 이 균형 잡힌 혼합 덕분에 모델을 훨씬 크게 학습시킬 수 있어 일상에서 사용하는 AI 서비스가 더 빠르고 안정적으로 제공됩니다.

💻 Developers
cmHC (Contraction for Manifold‑Constrained Hyper‑Connections) 은 Birkhoff polytope (the set of doubly stochastic matrices) 를 내부로 수축시켜 혼합 구성을 더 깊게 탐색하도록 합니다. 이 방법은 추가 파라미터 없이 가벼운 레이어 형태로 삽입할 수 있지만, 얕은 층에서 적절한 수축 정도를 설정하기 위해 약간의 연산 비용이 발생하며, 이를 통해 과도한 혼합을 방지하고 그래디언트 전파를 안정화합니다.

🔬 Researchers
cmHC 가 제공하는 내부 수축 메커니즘은 현재 대규모 사전 학습에서 안정성을 입증했지만, 최적의 수축 비율이 모델 규모와 데이터 분포에 따라 어떻게 변하는지는 아직 정량화되지 않았습니다. 또한, Birkhoff polytope 내부의 특정 영역이 학습 효율이나 일반화에 미치는 영향을 밝히기 위해서는 층별 수축 스케줄을 변형한 장기 ablation 연구가 필요합니다.
