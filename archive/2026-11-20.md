## 2. OpenSSL: Buffer overflow in EVP_EncodeBlock() (CVE-2026-121481, CVSS 9.8)

원문: <https://github.com/openssl/openssl/pull/33652> (Hacker News)

🌐 Everyone
OpenSSL 라이브러리의 base64 인코딩 함수가 특정 상황에서 메모리 버퍼를 초과 써서 프로그램이 갑자기 멈출 위험이 있었습니다. 이제 해당 함수가 잘못된 입력을 받으면 오류 코드를 반환하도록 바뀌어, 일반 사용자도 소프트웨어가 멈추는 일을 줄일 수 있게 되었습니다.

💻 Developers
이번 패치에서 도입된 'Base64 overflow 방어'는 EVP_EncodeBlock()와 EVP_DecodeBlock()이 입력 길이를 검사하고 오류 시 -1을 반환하도록 구현했습니다. 이 변화는 기존 호출 코드가 반환값을 확인하도록 수정해야 하며, 체크를 놓칠 경우 크기 변환 오류가 발생할 수 있다는 비용이 따릅니다.

🔬 Researchers
'Base64 overflow 방어'가 -1 반환 대신 assert를 선택하는 옵션 논의가 있었지만, 실제 배포 환경에서 오류 처리 정책이 어떻게 영향을 미칠지는 아직 명확히 규명되지 않았습니다. 또한, 다른 라이브러리와의 호환성을 유지하면서 오류 코드 표준화를 위한 추가 실험과 장기적인 보안 영향 분석이 필요합니다.

## 3. Jeveration: System One Models Now Generate

원문: <https://arxiv.org/abs/2611.24738> (Hugging Face Papers)

🌐 Everyone
새로운 AI 기술이 텍스트 설명만으로 사진을 바로 만들어 줍니다. 몇 초 안에 512×512 해상도의 그림이 완성돼서 스마트폰이나 웹에서 즉시 활용할 수 있습니다.

💻 Developers
Jeveration's single-pass generation은 고정된 vision‑language model에 무작위 상태를 결합해 한 번의 forward pass만으로 이미지를 출력합니다. 이 방식을 사용하면 78 ms 안에 512×512 이미지를 생성할 수 있지만, GPU 메모리와 연산량이 늘어나며 무작위 상태를 학습하기 위한 추가 코드가 필요합니다.

🔬 Researchers
Jeveration's single-pass generation이 전역 일관성을 유지하려면 무작위 상태와 이미지 코드 분포 사이의 최적 연결을 찾는 것이 아직 완전하지 않습니다. 또한 텍스트‑이미지, 이미지‑이미지, 밀집 예측을 하나의 체크포인트에서 동시에 수행하도록 설계했지만, 각 작업 간의 성능 트레이드오프와 확장성에 대한 정량적 분석이 부족합니다.
