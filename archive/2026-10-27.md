## 1. GPT-6.1 Terra

원문: <https://openai.com/index/introducing-gpt-6-1-terra/> (Hacker News)

🌐 Everyone
GPT-6.1 Terra는 빠르고 저렴하게 문서 작성, 그림 해석, 양식 입력, 영상 편집 같은 일상 업무를 자동화해 줍니다. 이 모델 덕분에 사무실 직원들은 반복 작업에 쓰는 시간을 줄이고, 더 창의적인 일에 집중할 수 있게 됩니다.

💻 Developers
이 모델을 우리는 “Terra”라 부르며, 시각 이해와 컴퓨터 제어를 결합해 API 호출 시 이미지와 화면을 직접 다룰 수 있게 설계되었습니다. 표준 API 가격은 입력 토큰당 $1, 캐시된 입력 토큰당 $0.05, 출력 토큰당 $5이며(토큰은 텍스트 조각 단위), 이전 버전 대비 비용이 50% 낮아 대량 자동화에 적합합니다.

🔬 Researchers
Terra의 비용 절감과 속도 향상이 실제로 어느 정도 모델 규모와 학습 데이터 증가에 기인했는지는 아직 명확히 구분되지 않았습니다. 또한, 복잡한 코딩이나 과학 실험 자동화에서 오류율을 더 낮추려면 추론 노력 단계별 효과를 정량화하는 추가 실험이 필요합니다.

## 2. Anthropic S-1

원문: <https://www.sec.gov/Archives/edgar/data/2130357/000162828026067168/anthropicpbc-sx1.htm> (Hacker News)

🌐 Everyone
Anthropic이 미국 증권거래위원회에 공개 등록 서류를 제출해 주식 공개를 준비하고 있습니다. 이를 통해 더 많은 투자금을 확보하면 AI 비서와 이미지 생성 서비스가 확대돼 일상에서 접할 기회가 늘어날 전망입니다.

💻 Developers
공개 등록 서류는 Class A 보통주를 발행하고, 조달된 자금을 대규모 compute 클러스터와 모델 훈련, API 인프라 확장에 사용할 계획이라고 명시합니다. 이러한 자금 투입은 API 사용료 상승과 엔드포인트 확장 비용 증가로 이어져, 서비스 통합 시 비용‑효율성을 재평가해야 할 필요가 있습니다.

🔬 Researchers
공개 등록 서류에서 제시된 자금 사용 방안은 안전성 연구와 모델 정밀도 향상에 대한 구체적 로드맵이 부족합니다. 따라서 실제 연구 성과와 투자 규모 사이의 인과관계를 밝히기 위해 장기적인 성능 추적과 안전성 평가 메트릭을 설계해야 합니다.

## 3. Reading, Writing, Sharing, and Interacting with the World through Video

원문: <https://arxiv.org/abs/2610.31668> (Hugging Face Papers)

🌐 Everyone  
최신 비디오 AI는 영상만 보는 것이 아니라, 그 속에 담긴 실제 세계의 흐름을 파악하고 새롭게 만들 수 있습니다. 이를 통해 일상에서는 자동 편집, 가상 회의 배경 생성, 그리고 실시간 상황 인식 기반 서비스가 더욱 자연스럽게 제공될 전망입니다.  

💻 Developers  
개발자는 이를 'world modeling'이라는 프레임워크로 묶어, 읽기(reading)로 상태 추론, 쓰기(writing)로 영상 합성, 공유(sharing)로 모델 재사용, 상호작용(interacting)으로 행동 기반 예측을 하나의 파이프라인에서 호출할 수 있습니다. 다만 이러한 파이프라인은 대규모 비디오 데이터와 고성능 GPU가 필요하며, 실시간 응답을 위해 연산량과 지연 시간을 균형 맞추는 비용이 따릅니다.  

🔬 Researchers  
연구진은 긴 영상에서 지속적인 잠재 세계 상태를 유지하고, 물리·인과 관계를 정확히 반영하는 'state consistency'와 'causal validity'를 동시에 달성하는 방법이 아직 충분히 정립되지 않았다고 지적합니다. 또한 평가 기준을 단순 시각 품질을 넘어 상호작용 효율과 downstream decision impact까지 포괄하도록 설계하는 것이 현재 큰 과제로 남아 있습니다.
