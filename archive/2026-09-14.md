## 1. Fable 5.1 Solves the Cyphral Distich, a 370-year-old cipher

원문: <https://www.vals.ai/blogs/fable-solves-cyphral-distich> (Hacker News)

🌐 Everyone
인공지능이 사람의 개입 없이 스스로 추론하여 370년 동안 풀리지 않던 역사적 암호를 해독해냈습니다. 외부의 복잡한 해독 열쇠 대신 책 내부의 특정 위치와 글자를 맞대어 읽는 단순한 원리를 찾아내어 숨겨진 글귀를 밝혀냈습니다.

💻 Developers
Fable 5.1 에이전트가 176k token에 달하는 문맥을 활용해 파이썬 파싱 스크립트를 작성하고 실행하며 book cipher(책 본문을 암호 키로 쓰는 기법) 구조를 정밀하게 복원했습니다. 장시간 대량의 연산을 지속하는 자율 루프가 동작하는 만큼 막대한 토큰 비용과 불완전한 OCR 텍스트 오차를 보정해야 하는 부담이 동반됩니다.

🔬 Researchers
원본 서적의 물리적 부재와 17세기 인쇄 오류로 인해 전체 암호문 중 9개 철자는 아직 명확한 평문으로 갈라내지 못했습니다. 이번 성과에서 모델의 자율적 가설 생성 능력과 스크립트 실행을 통한 탐색 성능이 각각 어느 정도 기여했는지를 통제 실험으로 분리해내는 연구가 이어져야 합니다.

## 2. 에이전트형 AI를 위한 데이터 준비하기

원문: <https://news.hada.io/topic?id=33657> (GeekNews)

🌐 Everyone
인공지능이 업무를 스스로 처리할 때 사람이 직관적으로 알아채던 잘못된 정보나 예전 기록을 그대로 믿고 실행하여 큰 손실을 내는 문제가 발생합니다.
이를 막으려면 인공지능에 넘겨줄 정보를 사전에 철저히 검증하고, 행동 단계마다 까다로운 확인 절차와 작업 기록을 남겨 권한을 점진적으로 맡겨야 합니다.

💻 Developers
Data Contract를 통해 schema와 freshness SLA(서비스 수준 협약)를 CI/CD 단계에서 강제하고, 검증에 실패한 데이터는 circuit breaker로 차단해 Gold layer만 agent에게 전달합니다.
OpenTelemetry 기반의 agentic lineage(판단 근거 및 경로 추적 체계)로 trace와 span을 기록해야 하지만, 비결정적 동작을 검증하기 위한 test harness 구축과 시스템 오버헤드가 발생합니다.

🔬 Researchers
데이터 품질 신호와 agent의 confidence score를 단일 수치로 결합하는 다변수 평가 지표가 여전히 부재하여, hard gate를 넘어서는 정교한 routing 수식의 정당성을 증명하기 어렵습니다.
Adaptive Gold 계층처럼 agent의 반복적 query pattern을 관찰하여 view를 자율 재구성하는 구조에서, 비결정적 추론에 따른 bias 누적과 data lineage 훼손 사이의 경계가 명확히 입증되지 않았습니다.

## 3. SenseNova-U1.5: Towards Native Unified Visual Intelligence

원문: <https://arxiv.org/abs/2609.11929> (Hugging Face Papers)

🌐 Everyone
인공지능이 별도의 이미지 변환 도구 없이 글자와 그림을 스스로 이해하고 최대 4K 고화질 이미지까지 직접 만들어내는 기술이 공개되었습니다. 복잡한 지시나 정교한 수정 요청도 정확하게 반영하여 원하는 형태의 복합 이미지나 카드뉴스를 쉽게 제작합니다.

💻 Developers
encoder-free 및 VAE-free(Variational Autoencoder, 데이터를 확률적으로 압축해 복원하는 생성 모델) 기반의 native unified 모델 구조로, multi-expert on-policy distillation을 통해 세부 전문가 모델을 하나로 통합했습니다. 고해상도 처리와 8B 파라미터 수준의 연산이 결합되어 추론 시 VRAM 소모와 계산 비용 부담이 커지는 대가가 따릅니다.

🔬 Researchers
visual understanding 능력이 visual generation 성능으로 직접 전이된 것인지, multi-expert 데이터의 단순 scaling 효과인지는 아직 갈라지지 않았습니다. 본질적인 unified modeling의 이점을 입증하려면 데이터 구축 방식과 reinforcement learning의 영향을 분리하여 검증하는 ablation 분석이 이어져야 합니다.
