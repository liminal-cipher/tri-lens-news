## 1. Infinite-Parameter LLMs: Generating and Adapting Weights from Live Data

원문: <https://arxiv.org/abs/2609.18842> (Hacker News)

🌐 Everyone
인공지능이 대화 중에 사용자가 입력한 새로운 사실이나 지적을 매번 길게 다시 읽지 않고 실시간으로 자신의 기억 방식 자체를 바꿔서 반영합니다. 이전 대화 기록을 길게 붙여넣지 않아도 되므로 긴 대화에서 답변 속도가 느려지거나 중요한 정보를 놓치는 일이 줄어듭니다.

💻 Developers
대화 내용을 prompt에 담는 in-context learning 대신 소형 hypernetwork가 실시간 데이터로 base network의 weight를 low-rank modulation(작은 규모의 가중치 변형) 방식으로 직접 구성합니다. 매 요청마다 prompt를 재연산하는 계산 부담은 줄어들지만, 대화 세션 동안 latent code의 Bayesian belief(확률적 불확실성 상태)를 계속 유지하고 업데이트해야 하는 서버 관리 대가가 따릅니다.

🔬 Researchers
실시간 weight 갱신이 긴 대화 동안 지속 누적될 때 기존 사전학습 지식을 파괴하는 catastrophic forgetting(파괴적 망각)을 완벽히 차단하는지가 아직 입증되지 않았습니다. 성능 향상이 hypernetwork 자체의 규모 때문인지 online 환경에서 추적되는 Bayesian belief 효과인지를 갈라내는 ablation(요소 제거 실험)이 수행되어야 합니다.

## 2. jcode - 수십 개 세션을 병렬로 실행하는 터미널 코딩 에이전트

원문: <https://news.hada.io/topic?id=33868> (GeekNews)

🌐 Everyone
소프트웨어 개발 시 한 가지 작업이 끝날 때까지 기다리지 않고 여러 인공지능 비서에게 일을 동시에 나누어 맡길 수 있는 도구가 나왔습니다. 컴퓨터 메모리를 거의 차지하지 않고 가볍게 작동하여 일상적인 프로그램 수정이나 검토 시간을 대폭 줄여줍니다.

💻 Developers
Rust 기반의 jcode는 세션당 10MB 수준의 메모리 footprint(프로그램이 실행될 때 차지하는 메모리 공간)를 유지하며 multi-agent architecture를 기반으로 하위 agent 생성 및 IPC(프로세스 간 통신) 방식의 파일 변경 통지를 처리합니다. 하지만 수십 개의 LLM agent를 동시 가동할 때 발생하는 API token 비용 문제와 파일 동시 수정 시 동기화 실패 리스크는 개발자가 감수해야 할 대가입니다.

🔬 Researchers
agent가 시작과 완료 시 측정한 self-evaluated confidence score(자체 평가 신뢰도 점수)의 급격한 변동을 감지해 재검증하는 기법이 hallucination을 실제 감소시키는지 정량적 평가가 부족합니다. 아울러 sub-agent 분업 시 발생하는 context drift(문맥 손실 및 왜곡) 현상이 base LLM의 reasoning 성능 부족 때문인지 agent 간 메시지 교환 protocol의 구조적 한계 때문인지 분리하여 검증해야 합니다.

## 3. Continual Learning Mechanisms Compose for Long-Horizon Memorization

원문: <https://arxiv.org/abs/2609.06986> (Hugging Face Papers)

🌐 Everyone
인공지능이 새로운 지식을 연속해서 배울 때 과거 내용을 까먹는 현상을 막기 위해 여러 기억 보존 방식을 하나로 섞어 쓰는 기술이 제안되었습니다. 이 기법을 쓰면 백 번에 걸쳐 새로운 정보를 이어 배워도 예전에 배운 답을 잊지 않고 맞히는 능력이 약 28배 상승합니다.

💻 Developers
continual supervised fine-tuning 환경에서 생기는 catastrophic forgetting(새 학습 시 기존 지식을 잃는 현상)을 해결하고자 세 가지 anchor와 merged LoRA를 결합합니다. 조합에 따른 탐색 공간이 급격히 커지므로 task-level successive halving을 도입해야 하며 탐색 과정에서 연산 자원이 크게 소모됩니다.

🔬 Researchers
data anchor와 merged LoRA 사이에서 발현된 super-additive(단순 합 이상의 시너지) 효과의 물리적 메커니즘은 정량적으로 규명되어야 할 과제입니다. 단순 텍스트 암기를 넘어 복잡한 long-horizon reasoning(장기 추론) 벤치마크에서도 앵커 조합의 유효성이 보전되는지 파악할 필요가 있습니다.
