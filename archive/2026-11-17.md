## 1. Running coding agents without handing them my credentials

원문: <https://blog.antonio.cx/running-agents-with-lend> (Hacker News)

🌐 Everyone  
원격 AI 코딩 에이전트가 내 노트북에 저장된 SSH 키와 1Password 토큰을 직접 복사하지 않고, 내 컴퓨터에서 명령을 실행하도록 요청합니다. 요청이 들어오면 Touch ID 로 승인하고 결과만 받아 보므로, 비밀번호가 외부 서버에 노출되는 위험 없이 코딩 자동화를 사용할 수 있습니다.  

💻 Developers  
lend는 기존 SSH agent 앞에 위치하는 proxy로, 에이전트가 실행하려는 명령을 소켓을 통해 전달하고, 노트북에서 실제 명령을 실행합니다. 정책 파일에 허용된 명령과 키만 허용하고, 각 요청마다 biometric approval(생체인증) 절차를 거치기 때문에 설정과 승인 단계가 추가되는 대가가 있습니다.  

🔬 Researchers  
lend의 정책 기반 승인 메커니즘은 현재 명령 단위와 키 지문 수준으로만 제한되어 있어, 복잡한 워크플로우에서 세밀한 권한 제어가 어려운 점이 남아 있습니다. 또한 프록시가 중간에 모든 SSH와 명령 트래픽을 가로채기 때문에, 공격자가 프록시 소켓을 탈취했을 경우 전체 인증 체계가 위험에 노출될 가능성을 체계적으로 평가할 필요가 있습니다.

## 2. AVA - AI 에이전트용 데이터 분석 및 시각화 프레임워크

원문: <https://news.hada.io/topic?id=37317&utm_source=geeknews&utm_medium=rss&utm_campaign=news> (GeekNews)

🌐 Everyone
AVA는 웹 앱이나 AI 비서에게 자연어로 데이터 분석 요청을 하면 자동으로 차트를 만들어 주는 JavaScript 기반 도구입니다. 예를 들어 “1월과 2월 매출을 제품별로 비교해 줘”라고 말하면, 내부에서 데이터베이스를 조회하고 결과와 요약, 적절한 그래프까지 보여줍니다.

💻 Developers
개발자는 npm 패키지 혹은 CLI 형태로 제공되는 AVA를 프로젝트에 추가하고, Node.js 환경에서는 DuckDB를 이용해 로컬에서 SQL을 실행합니다. LLM 호출 비용이 별도이며, 쿼리와 차트 설정이 JSON(GPT-Vis) 혹은 HTML 형태로 출력되므로 프런트엔드에 바로 삽입할 수 있습니다.

🔬 Researchers
AVA가 생성하는 SQL과 차트 추천이 복잡한 스키마나 모호한 질문에 대해 얼마나 정확한지, 자동화 과정에서 발생할 수 있는 편향을 체계적으로 평가하는 연구가 필요합니다. 또한 다중 데이터 소스 결합 시 성능과 보안 문제, 그리고 LLM 엔드포인트의 다양성에 따른 결과 일관성 차이를 규명하는 작업이 남아 있습니다.

## 3. Envisioning Agentic Robotics: A New Era of Robotic Systems

원문: <https://arxiv.org/abs/2611.18359> (Hugging Face Papers)

🌐 Everyone
새로운 로봇 시스템이 사람의 명령을 스스로 이해하고 행동합니다. 이 기술이 일상에 적용되면 가정용 로봇이 복잡한 일을 직접 맡아줄 수 있게 됩니다.

💻 Developers
이 시스템을 우리는 'agentic robotics'라 부릅니다. agentic robotics는 대규모 foundation model과 물리적 제어 하네스를 결합해 환경을 관찰하고 목표를 해석해 동작을 선택하지만, 실시간 추론 비용과 안전 검증 요구 때문에 하드웨어 사양과 응답 지연을 감수해야 합니다.

🔬 Researchers
agentic robotics는 일반적 추론을 물리적 제약에 맞춰 실행하는 과정에서 오류 전파와 불확실성 관리가 큰 난제로 남아 있습니다. 이를 해결하기 위해 지속적 자율성 평가 프레임워크와 물리‑인증 학습 기법을 통합한 로드맵이 제시되고 있습니다.
