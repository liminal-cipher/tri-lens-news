## 1. If I own Claude's outputs why can't I train my own model on them?

원문: <https://support.claude.com/en/articles/12326764-can-i-use-my-outputs-to-train-an-ai-model> (Hacker News)

🌐 Everyone
클로드에게서 얻은 결과물에 대한 소유권은 사용자에게 귀속되지만 이 답변들을 모아 새로운 인공지능을 만드는 재료로 활용하는 것은 금지됩니다. 직접 작성한 글과 동일하게 제품을 만들거나 유통하는 것은 가능하지만 경쟁 인공지능을 개발하는 데 쓰는 순간 약관 위반이 됩니다.

💻 Developers
앞서 언급한 "인공지능을 만드는 재료"가 synthetic data(모델이 생성해낸 학습용 데이터)이며, 이를 이용해 파라미터를 개선하는 distillation(상위 모델의 지식을 하위 모델로 이전하는 기법)이 금지 대상입니다. API로 수집한 응답을 로컬 모델 학습 파이프라인에 투입하면 서비스 약관 위반으로 계정이 차단되는 대가를 치르게 됩니다.

🔬 Researchers
앞의 synthetic data와 distillation 규제에도 불구하고 단순한 도메인 fine-tuning(특정 목적에 맞게 모델을 미세조정하는 작업)과 제재 대상인 무단 지식 추출을 기술적으로 구분하는 기준은 수립되지 않았습니다. 생성물 검출을 위한 워터마킹이나 오프라벨 학습 추적 알고리즘의 한계로 인해 약관 위반 여부를 실질적으로 검증하는 평가 방식이 여전히 공백으로 남아 있습니다.

## 2. Qwen3.8-2.4T-A95B 오픈 웨이트 공개

원문: <https://news.hada.io/topic?id=32445> (GeekNews)

🌐 Everyone
거대 인공지능 모델의 모든 설계도와 학습 결과물이 전 세계에 무료로 공개되었습니다.
방대한 지식을 담고 있지만 질문을 처리할 때는 필요한 일부 기능만 골라 작동시켜 처리 효율을 높였습니다.

💻 Developers
앞에서 언급한 일부만 골라 작동하는 방식이 MoE(Mixture of Experts, 여러 전문 신경망을 조합해 사용하는 기법) 구조이며, 전체 2.4T개 parameter(모델의 학습 파라미터) 중 95B개만 활성화됩니다.
추론 시 연산량이 줄어드는 이점이 있지만, 실행 과정에서 2.4T 전체 weight를 메모리에 유지해야 하므로 거대한 VRAM 확보가 필수적입니다.

🔬 Researchers
앞서 다룬 MoE 모델에서 expert(세부 전문 신경망) 수의 확장과 active parameter 비중 변화가 특정 성능에 미치는 개별적 영향은 아직 투명하게 분리되지 않았습니다.
또한 weight만 오픈되었을 뿐 pre-training(사전 학습) 데이터셋과 routing(신호를 알맞은 전문가로 연결하는 알고리즘)의 구체적인 제어 조건이 비공개여서 완전한 실험 재현에는 한계가 있습니다.

## 3. On-Policy Self-Distillation without Any Supervision

원문: <https://arxiv.org/abs/2608.06296> (Hugging Face Papers)

🌐 Everyone
인공지능이 사람이 정답을 알려주지 않아도 스스로 여러 번 답을 풀어본 뒤 가장 많이 나온 결과를 기준 삼아 자신의 오류를 수정하는 기술이 개발되었습니다. 이로 인해 정답지가 없는 복잡한 수학이나 논리 문제에서도 모델을 추가로 학습시켜 성능을 올릴 수 있게 되었습니다.

💻 Developers
앞서 언급한 자율 수정 방식은 self-consistency(여러 번 답을 생성해 다수결로 판정하는 기법) 조건으로 가짜 정답을 구성하고 자신의 오류를 교정하는 U-OPSD입니다. 외부 라벨 없이 기존 OPSD나 GRPO 같은 지도 학습 수준의 성능을 내지만, 학습 중 다수의 rollout을 생성해야 하므로 컴퓨팅 비용과 VRAM 소모가 커집니다.

🔬 Researchers
앞의 두 관점에서 다룬 가짜 정답 방식은 초기 모델의 정답률이 낮을 때 잘못된 답이 다수결을 차지하여 오류를 강화하는 error cascade(오류가 꼬리를 물고 증폭되는 현상) 문제를 남깁니다. 또한 non-thinking mode에서의 성능 개선이 단순 답안 일치율 향상 때문인지 실제 추론 능력의 확장에 의한 것인지 변수가 완벽히 분리되지 않았습니다.
