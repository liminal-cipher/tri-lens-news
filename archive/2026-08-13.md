## 1. Qwen3.8-2.4T

원문: <https://huggingface.co/Qwen/Qwen3.8-2.4T-A95B> (Hacker News)

🌐 Everyone
전체 크기는 엄청나게 커졌지만 질문을 받을 때 필요한 부분만 골라 사용하여 답을 찾아냅니다. 이 변화로 복잡한 전문 지식이나 긴 논리를 다루는 작업에서 한층 정확한 답변을 받습니다.

💻 Developers
앞에서 언급한 필요한 부분만 골라 쓰는 구조가 Mixture-of-Experts (MoE; 전문가 혼합)이며, 답을 낼 때 실제로 작동하는 부위는 active parameters (활성 매개변수)라 부릅니다. 추론 연산량은 줄어들지만 2.4T 전체 weight (가중치)를 메모리에 상주시켜야 하므로 VRAM (비디오 램) 확보 비용이 부담으로 작용합니다.

🔬 Researchers
앞의 MoE 구조에서 얻은 성능이 전체 parameter (매개변수) 용량 증가에 기인한 것인지 아니면 router (경로 배정기)의 효율적 분배 때문인지가 분리되지 않았습니다. 두 요인을 통제하려면 router의 routing policy (경로 배정 정책)를 고정한 채 active parameters 비율만 바꿔가며 측정하는 ablation (요소 제거 실험)이 수행되어야 합니다.

💻 Developers

🔬 Researchers

## 3. On-Policy Self-Distillation without Any Supervision

원문: <https://arxiv.org/abs/2608.06296> (Hugging Face Papers)

🌐 Everyone
사람이 직접 정답을 매기거나 외부의 도움을 받지 않고도 인공지능 모델 스스로 틀린 답을 바로잡는 새로운 학습법이 등장했습니다. 모델이 스스로 여러 번 답을 낸 뒤 가장 많이 겹치는 논리를 바탕으로 자가 교정을 거치며 수학이나 추론 문제의 정확도를 높입니다.

💻 Developers
앞서 언급한 여러 답을 내어 다수결로 기준을 정하는 기법이 self-consistency (자기 일관성) 기반의 pseudo-solution (의사 정답) 추출이며, 이를 unsupervised on-policy self-distillation (비지도 온폴리시 자가 증류)이라 부릅니다. 이를 적용하려면 모델을 훈련할 때마다 다수의 rollout (생성 결과물)을 연달아 출력하고 검증해야 하므로 연산 자원과 학습 시간이 대폭 증가합니다.

🔬 Researchers
지도 학습 없이 기존 OPSD (온폴리시 자가 증류)나 GRPO (그룹 상대 정책 최적화)에 비견되는 성과를 냈으나, 다수결 원리가 통하지 않는 비구조화된 텍스트 생성 영역에서도 유효한지는 파악되지 않았습니다. 또한 성능 향상이 모델 고유의 pure self-correction (순수 자가 수정) 능력에서 비롯되었는지, 단순히 설정한 임계값에 의한 노이즈 필터링 결과인지 변수 분리 검증이 필요합니다.
