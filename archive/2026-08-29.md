## 1. 바이브코딩으로 만든 퍼저가 FFmpeg의 0 나누기 버그를 발견

원문: <https://news.hada.io/topic?id=33001> (GeekNews)

🌐 Everyone
동영상이나 음성을 재생하는 유명 소프트웨어 부품에서 특수하게 만든 21바이트 크기의 가짜 파일을 열면 프로그램이 바로 강제 종료되는 결함이 발견되었습니다. 이 결함은 시스템을 파괴하거나 정보를 빼가지 못하지만, 서비스를 계속해서 멈추게 만드는 공격에 악용될 수 있습니다.

💻 Developers
이 문제는 FFmpeg의 VPK demuxer(미디어 컨테이너 해석기)가 패킷을 읽을 때 채널 수가 0인 상황을 검사하지 않아 SIGFPE(정수 0 나누기 예외)를 일으키는 현상입니다. 헤더 파싱 단계의 검증을 우회하는 입력 시 crash가 발생하므로, 패킷 처리 함수 진입부에 채널 수 검사를 추가하고 AVERROR_INVALIDDATA를 반환하도록 방어 조치를 해야 합니다.

🔬 Researchers
AI로 구현한 fuzzer(무작위 입력을 넣어 결함을 찾는 무작위 테스트 도구)가 10시간 동안 50만 회 가깝게 실행되어 발견한 이 결함은 상태 변경 가능성을 활용한 경계 조건 탐색의 유효성을 보여줍니다. 다만 이것이 바이브코딩으로 생성된 fuzzer 고유의 탐색 전략 효율성 때문인지, 단순 시간 투입으로 사용자 정의 AVIO 경로의 입력 불일치를 찾아낸 것인지 단정하기는 어렵습니다.

## 2. GLM-5.3, 오픈 웨이트로 공개

원문: <https://news.hada.io/topic?id=32989> (GeekNews)

🌐 Everyone
기존과 같은 기본 뼈대를 유지하면서 학습 방식만 개선해 복잡한 코딩과 긴 작업을 처리하는 능력을 대폭 높인 인공지능이 무료로 공개되었습니다.
컴퓨터를 제어하고 보안 약점을 찾는 일도 더 잘하게 되어 복잡한 업무 자동화의 정확도가 크게 올라갑니다.

💻 Developers
post-training(사전 학습 이후 진행하는 추가 학습) 기법이 적용된 가중치를 vLLM이나 SGLang 환경에 올려 직접 배포 및 미세 조정을 진행할 수 있습니다.
다만 벤치마크 수준의 성능을 재현하려면 reasoning_effort 옵션을 max로 고정해야 하므로 추론 지연과 연산 자원 소모가 늘어나는 대가를 치러야 합니다.

🔬 Researchers
동일한 base model을 유지한 상태에서 post-training만으로 코딩 성능이 오른 원인이 단순 reinforcement learning 연산량 증가 때문인지 에이전트 전용 데이터셋 효과인지가 명확히 분리되지 않았습니다.
특히 보안 평가인 CyberGym 성과가 일반적인 도구 사용 역량의 부수 효과인지 파악하기 위한 ablation(구성 요소를 하나씩 제거해 효과를 검증하는 실험)이 필요합니다.

## 3. VGI-Bench: Probing Visual Intelligence in Video Generation Models

원문: <https://arxiv.org/abs/2608.19583> (Hugging Face Papers)

🌐 Everyone
최신 비디오 생성 AI가 영상 속 물체의 이동이나 복잡한 문제를 풀어내며 스스로 사고하는 듯하지만 실제 성공률은 높지 않습니다.
가장 뛰어난 모델도 정답률이 51%에 머무르며, 영상 생성 초기 단계에서 잘못 판단하면 뒤로 갈수록 오류를 바로잡지 못하고 엉뚱한 결과를 냅니다.

💻 Developers
VGI-bench는 비디오 생성 모델의 zero-shot visual reasoning(별도 학습 없이 시각 정보만으로 추론하는 능력)을 평가하며, 완성본뿐만 아니라 과정 프레임의 논리적 연속성을 함께 검증합니다.
노이즈를 단계적으로 제거하는 denoising(이미지나 비디오의 잡음을 제거하며 정제하는 과정) 단계에서 self-correction이 작동하지 않으므로, 추론 기반 비디오 파이프라인 구축 시 초기 조건 제어가 핵심 변수로 작용합니다.

🔬 Researchers
synthetic fine-tuning(가상 데이터 기반 미세조정)을 통한 연산 능력 전개의 한계와 생성 초기 단계의 추론 오류가 후속 단계로 고착화되는 메커니즘을 규명해야 합니다.
시각적 그럴듯함과 실제 물리 연산의 타당성 간 결합을 해소하고, 노이즈 제거 공간 내에서 논리 오류를 수정하도록 유도하는 아키텍처 전환이 필요합니다.
