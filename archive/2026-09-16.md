## 1. Introducing System One Models and Jev

원문: <https://typesafe.ai/blog/introducing-system-one-models-and-jev> (Hacker News)

🌐 Everyone
문장을 하나씩 지어내며 대화하는 대신, 입력된 정보를 바탕으로 소프트웨어가 필요한 판정을 0.1초도 안 되는 시간에 정확히 내려주는 새로운 인공지능이 나왔습니다. 글을 쓰지 않는 대신 환각 현상이 사라지고 응답 속도가 비약적으로 빨라져, 일상적인 서비스 내부에서 판단이 필요한 작업들이 지연 없이 실시간으로 처리됩니다.

💻 Developers
텍스트 생성 기능을 포기하고 parallel sampling(모든 출력을 단일 쿼리로 한 번에 처리하는 방식)을 도입하여 type-safe structured values를 정형화된 확률값과 함께 반환합니다. 일반적인 LLM에 비해 속도가 최고 200배 빠르고 출력 토큰 비용이 발생하지 않지만, 자율적인 문장 작성이나 코드 생성을 수행하지 못하므로 오직 조건 판단이나 라우팅 모듈 용도로만 조립해 써야 합니다.

🔬 Researchers
RLCD(Reinforcement Learning for Calibrated Decisions, 교정된 결정을 위한 강화학습)를 통한 확률 교정 성능이 연쇄적 추론 과정이 생략된 상태에서도 OOD(out-of-distribution, 학습 데이터 범위를 벗어난 분포) 상황까지 안정적으로 유지될지는 아직 입증되지 않았습니다. 또한 모델의 오차 없는 타입 보장이 아키텍처 차원의 하드 제약인지 디코딩 단계의 마스킹 기법에 불과한지 구체적인 세부 구현 알고리즘이 공개되어야 엄밀한 verification이 완료됩니다.

## 2. Gemini 3.8 Live and 3.8 Live Extended Thinking

원문: <https://blog.google/innovation-and-ai/models-and-research/gemini-models/gemini-3-8-live-gemini-3-8-live-extended-thinking/> (Hacker News)

🌐 Everyone
AI와 음성으로 대화할 때 대답을 지루하게 기다릴 필요 없이 자연스럽게 이야기를 주고받으며 복잡한 일도 처리할 수 있습니다.
AI가 뒤에서 정보를 찾거나 다른 작업을 수행하는 동안에도 대화를 멈추지 않고 진행 상황을 생생하게 설명해 줍니다.

💻 Developers
Live API 기반의 background tool calling을 비동기로 실행하며 real-time streaming으로 소통을 유지하는 구조입니다.
extended thinking을 음성 합성과 동시 처리하여 대화 연속성을 확보하지만 연산량 증가에 따른 토큰 비용 부담이 커집니다.

🔬 Researchers
simultaneous reasoning(추론과 음성 생성을 동시에 진행하는 것)에서 모델 성능의 향상이 추론 능력의 진보인지 사전 추론 표현 삽입 효과인지 분리하는 ablation(요소 제거 실험)이 부족합니다.
자율적인 tool calling 수행 시 생성되는 audio watermarking의 강인성과 파라미터 제어 간의 상관관계도 추가 규명이 필요합니다.

## 3. Vidu S2: Real-Time Interactive, Editable, and Spatial Video Generation

원문: <https://arxiv.org/abs/2609.11638> (Hugging Face Papers)

🌐 Everyone
화면 속 가상 인물이 사용자의 입력에 즉각 반응해 움직이고 방송 중에 옷이나 배경을 실시간으로 바꾸는 기술이 나왔습니다. 영상을 생성하고 편집할 때 대기 시간이 사라져 대화형 서비스나 실시간 스트리밍 환경에서 유용하게 쓰입니다.

💻 Developers
720p 해상도를 지원하는 Vidu S2-Avatar의 dynamic reference 제어와 Vidu S2-Editing의 real-time stream editing 구조는 높은 VRAM 용량과 극도로 낮은 latency(응답 지연 시간)를 요구합니다. 실시간 비디오 스트림을 변환할 때 GPU 리소스 소비가 급증하므로 클라이언트 네트워크 변동에 따른 프레임 드롭 대책을 세워야 합니다.

🔬 Researchers
spatial video generation(입체 공간 영상 생성) 과정에서 temporal consistency(시간적 일관성)를 보장하면서 실시간 처리 속도를 달성한 이론적 원리가 명확히 밝혀지지 않았습니다. 렌더링 품질 향상이 인퍼런스 구조의 개선 결과인지 모델 규모의 확장에 기인한 것인지를 검증하는 ablation 연구가 더 이어져야 합니다.
