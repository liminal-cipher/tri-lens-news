## 1. WeatherNext 3: Our most advanced global weather AI model

원문: <https://blog.google/innovation-and-ai/models-and-research/google-deepmind/introducing-weathernext-3/> (Hacker News)

🌐 Everyone
기상 슈퍼컴퓨터의 오랜 계산을 기다리지 않고 인공지능이 위성 사진과 실제 측정소 정보를 직접 읽어 한 시간마다 날씨를 예측합니다. 지형이 복잡한 산간이나 해안 지역에서도 비나 기온의 변화를 훨씬 세밀하게 파악할 수 있습니다.

💻 Developers
기존 NWP(Numerical Weather Prediction, 수치 기상 예측)의 6시간 데이터 시차를 없애기 위해 live geostationary satellite mosaics와 sparse station observations를 FGN(Functional Generative Network) mesh transformer에 직접 투입합니다. 5km spatial resolution 추론과 시간당 수집을 감당하려면 대규모 실시간 파이프라인 구축과 고해상도 텐서 처리 비용을 부담해야 합니다.

🔬 Researchers
성능 향상이 FGN 개선 때문인지 아니면 IMERG 및 레이더 데이터셋 증대 때문인지 기여도를 분리한 ablation 분석이 부족합니다. 아울러 generative model 특유의 아티팩트 없이 물리적 보존 법칙을 만족하며 극단적 precipitation 경계를 정교하게 형성하는지는 지속적인 검증이 필요합니다.

## 2. Terence Tao: “AI만으로 수학 문제를 성급하게 푸는 것”의 위험

원문: <https://news.hada.io/topic?id=33326> (GeekNews)

🌐 Everyone
인공지능이 복잡한 수학이나 과학 문제의 정답만 단번에 제시하고 해결 과정은 숨기는 시나리오가 우려를 낳고 있습니다. 정답을 구하는 과정에서 얻는 깨달음과 시행착오를 공유받지 못하면 당장의 답은 얻을지 몰라도 미래의 연구자를 키우고 인류 전체의 지식을 확장할 기회를 잃게 됩니다.

💻 Developers
기업이 자율 AI harness(모델의 탐색 과정을 자동으로 제어하는 시스템)로 내부 연산을 마치고 결과만 공개하는 방식은 단기적인 benchmark 홍보 수단으로 전락하기 쉽습니다. 문제 해결 과정에서 LLM이 제시한 ansatz(해의 예측 형태)와 수치 시뮬레이션 결과를 Lean 언어로 형식 검증하여 외부로 투명하게 공유해야 시스템의 오류를 수정하고 코드 및 이론을 재사용할 수 있습니다.

🔬 Researchers
Navier-Stokes 방정식에서 finite-time singularity(유한한 시간 내에 값이 무한대로 발산하는 특이점)의 존재 여부가 확정되지 않은 상황에서, AI가 제시한 수치 근사의 잔차가 실제 해의 안정성 임계값 내에 존재하는지 엄밀하게 보증할 방법이 미비합니다. 블랙박스화된 결과물을 역공학해서 얻는 지식과 막다른 탐색 경로의 실패 원인을 분석하여 얻는 해석학적 통찰 간의 가치 차이를 정량적으로 분리해 평가할 학술적 기준도 아직 마련되지 않았습니다.

## 3. Random Attention: Rethinking KV Cache Eviction for Efficient Reasoning

원문: <https://arxiv.org/abs/2609.03430> (Hugging Face Papers)

🌐 Everyone
인공지능이 복잡한 문제를 풀 때 중간 생각 과정을 무작위로 지워도 답변 정확도가 유지된다는 사실이 밝혀졌습니다. 처음에 입력한 질문만 남겨두면 임시 저장 공간을 크게 줄여 훨씬 빠른 속도로 답변을 받게 됩니다.

💻 Developers
KV cache(이전에 처리한 정보 목록을 보관하는 메모리) 압축 시 점수를 구하지 않고 토큰을 무작위로 지우는 Random Attention 방식을 적용하면 vLLM 환경의 처리량을 최대 43% 향상시킵니다. 점수 계산 연산을 없애는 이점이 명확하지만 추론 트레이스 내 텍스트 중복성과 프롬프트 보존 규칙에 전체 정확도가 좌우됩니다.

🔬 Researchers
성능 유지가 텍스트 자체의 표현 중복성 때문인지 multi-head attention(여러 관점에서 문맥을 파악하는 연산 단위) 간의 정보 복제 효과 때문인지 별도로 분리하여 측정하지 못했습니다. 추론 과정의 표현 중복성을 차단한 조건에서도 동일한 무작위 추출 효율이 유지되는지 따져보는 ablation study(구성 요소를 제거하며 영향을 측정하는 실험)가 요구됩니다.
