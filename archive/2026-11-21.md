## 1. Language Models Can Rewrite Their Own Weights

원문: <https://arxiv.org/abs/2611.21885> (Hacker News)

🌐 Everyone  
언어 모델이 스스로 내부 설정을 고쳐서 성능을 높일 수 있게 되었습니다. 이 기술이 적용되면 서비스가 별도 업데이트 없이도 점점 더 정확해져 사용자 경험이 지속적으로 개선됩니다.  

💻 Developers  
이를 self‑rewriting이라 부르며, 모델이 현재 가중치(weight)와 답안 평가를 기반으로 오류를 찾아낸 뒤, 순전파(forward pass)만으로 새로운 가중치를 생성하고 적용합니다. 이 과정은 추가적인 역전파(backpropagation) 없이 진행되지만, 수정 후보를 검증하기 위한 여러 번의 순전파와 임시 가중치 저장을 위해 GPU 메모리와 연산 시간이 늘어납니다.  

🔬 Researchers  
self‑rewriting이 장기적으로 모델의 지식 구조를 어떻게 변형시키는지와, 반복 수정이 안정성을 해치지 않을지에 대한 이해가 아직 부족합니다. 또한, 악의적 수정 방지를 위한 안전 메커니즘과 다양한 작업에 걸친 정량적 평가가 필요한 상황입니다.

## 2. Restricting AI agents in mobile operating systems platforms from capturing data

원문: <https://signal.org/blog/protecting-your-privacy/> (Hacker News)

🌐 Everyone  
Signal은 iOS 27 및 Android에서 화면을 읽으려는 AI 비서가 메시지를 캡처하지 못하도록 기본적으로 차단합니다. 이 설정 때문에 사용자는 앱 안에서 스크린샷을 바로 찍을 수 없으며, 필요 시 설정을 켜서 허용하면 대화 내용이 AI에 노출될 위험이 있습니다.  

💻 Developers  
이를 ‘AI Screen Guard’라 부르며, 앱 레벨에서 OS의 스크린샷 API와 화면 읽기 요청을 차단해 AI agent가 화면 데이터를 수집하지 못하게 합니다. 다만 사용자가 설정에서 보호를 해제하면 차단이 해제되고, 파일 시스템 접근 같은 다른 경로는 아직 완전히 막을 수 없어 보안 비용과 사용성 사이의 균형을 맞춰야 합니다.  

🔬 Researchers  
현재 OS 공급자가 AI agent의 동작 방식과 데이터 흐름을 상세히 공개하지 않아 ‘AI Screen Guard’가 차단하지 못하는 은밀한 채널이 존재하는지 여부를 정확히 판단하기 어렵습니다. 따라서 파일 시스템 스캔, 접근성 서비스 남용 등 잠재적 침해 경로를 정량화하고, 표준화된 OS‑level 프라이버시 인터페이스를 설계하는 연구가 시급합니다.

## 3. WeVisForensics: Self-Evolving Agent for Omni AI-Generated Video Detection

원문: <https://arxiv.org/abs/2611.21373> (Hugging Face Papers)

🌐 Everyone
AI가 만든 매우 사실적인 영상이 늘어나면서, 이를 진짜와 구분하기 어려워 사회적 혼란이 커지고 있습니다. 새로운 가짜 영상 탐지 시스템인 WeVisForensics는 화면과 소리의 작은 이상 징후를 찾아내어, 사용자와 서비스 제공자가 위조된 영상을 빠르게 판별하도록 돕습니다.

💻 Developers
WeVisForensics는 메인 조사 에이전트가 시각·청각 단서별 검사 에이전트를 호출하고, 어느 구간을 살펴볼지와 언제 결론을 내릴지를 학습하는 구조로, 빠른 강화학습(RL)과 느린 파라미터 업데이트를 결합한 DTPO 방식을 적용합니다. 이 시스템은 ForenCue‑30K 데이터셋의 역할별 라벨과 상호작용 로그를 활용해 검사 에이전트를 지속적으로 진화시키며, 실행 시 GPU 메모리와 연산량이 기존 탐지기 대비 약간 증가하지만 높은 정확도를 제공합니다.

🔬 Researchers
WeVisForensics가 다양한 도메인에서 95% 이상의 정확도를 보이지만, 아직 완전히 새로운 생성 모델이나 압축된 스트리밍 환경에서의 미세한 변조를 놓칠 가능성이 남아 있습니다. 또한 검사 에이전트의 진화 메커니즘이 어떤 종류의 인공 신호에 가장 민감한지, 그리고 지속적인 학습이 장기적으로 검출 편향을 초래하지 않을지에 대한 체계적인 분석이 필요합니다.
