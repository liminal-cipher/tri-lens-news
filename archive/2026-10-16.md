## 1. Neural networks are clean

원문: <https://already-clean.goodfire.com/> (Hacker News)

🌐 Everyone
신경망이 복잡하게 얽혀 있다고 보던 기존 인식이 바뀌어, 내부 구조가 비교적 명확하게 드러납니다. 따라서 이미지 검색이나 대화형 서비스 같은 일상 애플리케이션에서 예기치 않은 행동이 줄어들게 됩니다.

💻 Developers
CleanNet은 원본 모델의 뉴런과 회로를 직접 분석해 기능을 규명하는 방법이며, 별도의 분해 모델을 훈련할 필요가 없습니다. 다만 대규모 모델을 다룰 경우 많은 GPU 메모리와 자동화된 실험 파이프라인이 요구됩니다.

🔬 Researchers
약한 활성화와 recursive generalization의 정확한 수학적 정의는 아직 연구가 진행 중이며, 이를 분리하는 실험 설계가 필요합니다. 특히 전체 뉴런 중 소수만이 여전히 다중 역할을 보이며, 이러한 현상의 원리를 밝히는 것이 앞으로의 과제입니다.

## 2. Krea 3 – An image model built for editing at scale

원문: <https://www.krea.ai/krea-3> (Hacker News)

🌐 Everyone  
Krea 3는 사진 안에서 바꾸고 싶은 부분만 선택하면 AI가 나머지는 그대로 두고 빠르게 바꿔 주는 서비스입니다. 한 장당 몇 달러 정도면 대량으로 사용할 수 있어 쇼핑 사진이나 광고 제작을 손쉽게 바꿀 수 있습니다.  

💻 Developers  
Krea 3는 region‑based rendering을 이용해 편집 영역만 재생성하고, 2K 해상도를 네이티브로 출력합니다. API 호출당 list price가 적용되며, 응답 시간은 8초 수준으로 설계돼 대규모 파이프라인에 적합합니다.  

🔬 Researchers  
region‑based rendering이 실제로 전체 이미지 일관성을 얼마나 유지하는지 정량적 평가가 부족합니다. 또한 비용‑성능 모델이 다양한 GPU 사양에서 어떻게 변동하는지와 편향(bias) 문제는 추가 연구가 필요합니다.

## 3. Cortex: Consolidating Context into Parametric Memory

원문: <https://arxiv.org/abs/2610.20399> (Hugging Face Papers)

🌐 Everyone
AI가 제공된 배경 정보를 활용해 성능을 올렸다가, 그 배경을 없애도 개선된 능력을 유지하도록 만든 기술입니다. 이 덕분에 모델이 특정 작업을 더 잘 수행하면서도 기존에 잘하던 다른 일은 그대로 유지됩니다.

💻 Developers
이 방식을 Cortex라 명명합니다. Cortex는 잠재적인 질의를 만들고, 컨텍스트에 의한 출력을 저차원 또는 구조적 feed‑forward 업데이트로 압축해 모델에 적용하는데, 추가 연산과 메모리가 요구됩니다.

🔬 Researchers
Cortex가 단일·배치·연속 업데이트에서 높은 보존률을 보이지만, 장기간에 걸친 순차적 편집이 모델 안정성에 미치는 영향을 완전히 규명하지 못했습니다. 또한 저차원 업데이트와 구조적 업데이트 사이의 효율성 차이를 정량화하려면 보다 정교한 ablation 실험이 필요합니다.
