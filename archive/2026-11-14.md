## 1. Anthropic Upgrades Claude Code Projects to Run Parallel AI Workers Hands-Free

원문: <https://alphasignal.ai/news/anthropic-upgrades-claude-code-projects-to-run-parallel-ai-workers-hands-free> (Hacker News)

🌐 Everyone
Anthropic가 Claude Code Projects에 자동 작업 배정과 진행 상황 알림 기능을 추가했습니다. 이를 통해 여러 코드 작업을 동시에 진행하면서 일일이 확인할 필요가 없어 시간과 손길을 절약할 수 있습니다.

💻 Developers
이 서비스를 우리는 “Parallel AI Workers”라고 부릅니다. 코디네이터가 각 작업을 별도 클라우드 세션에 할당하고, /btw·/fork 명령어와 리마인더로 흐름을 제어하며, 사용량은 기존 Claude Code 할당량에서 차감되고 하루 200개의 새 세션 제한과 고부하 모델 선택에 따라 비용이 증가합니다.

🔬 Researchers
Parallel AI Workers는 동시성 충돌 해결과 로컬 파일 접근 제한 등 아직 완전히 해결되지 않은 제약이 존재합니다. 특히 여러 작업이 같은 코드베이스를 수정할 때 발생하는 merge conflict와 플랜 한도 소모가 모델 선택 및 작업 스케줄링에 미치는 영향을 체계적으로 분석하는 연구가 필요합니다.

## 3. SO-Arena: Benchmarking the Capability Spectrum and Reliability of System One Models

원문: <https://arxiv.org/abs/2611.15777> (Hugging Face Papers)

🌐 Everyone
새로운 SO-Arena 평가지가 빠른 의사결정 AI 모델이 어떤 일을 할 수 있는지와 그 판단이 얼마나 믿을만한지를 폭넓게 살펴줍니다. 이 정보를 바탕으로 일상적인 검색, 추천, 자동화 등에서 AI가 실수를 줄이고 신뢰를 높이는 서비스를 기대할 수 있습니다.

💻 Developers
이 평가지, 즉 SO-Arena benchmark는 11개 분야와 다섯 가지 능력군을 대상으로 증거 기반 평가, 난이도 기준, 그리고 sandbox (격리된 실행 환경)에서의 상호작용 테스트를 결합합니다. 동시에 결정 안정성 및 답이 없을 때 인식하는 신뢰도 지표를 추가해 평가 비용과 라벨링 작업이 크게 늘어나는 대가가 따릅니다.

🔬 Researchers
현재 모델들 사이에서 규모 확장이 항상 신뢰도 향상으로 이어지지 않는다는 사실이 드러났으며, 어떤 분야에서 신뢰도가 떨어지는지 정확히 예측하는 방법이 부족합니다. 따라서 신뢰도와 정확성을 동시에 최적화할 수 있는 평가 프레임워크와, 부족한 옵션을 자동으로 감지하는 메커니즘 개발이 연구 과제로 남아 있습니다.
