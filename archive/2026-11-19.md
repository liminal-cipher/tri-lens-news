💻 Developers  
Reticle 자동 검증 에이전트는 코드 변경 후 npx @reticlehq/server 명령으로 앱을 실행해 UI 조작, API 호출, 콘솔 로그 등을 실시간으로 수집하고 통과 여부를 판단합니다.

## 3. TeleChat to Xing4: Advancing Frontier Agentic Models on Domestic Chips and Frameworks

원문: <https://arxiv.org/abs/2611.22115> (Hugging Face Papers)

🌐 Everyone
새로운 AI 모델이 국내 칩을 활용해 대규모로 학습되었습니다. 이 모델은 일상 생활 속 디지털 기기들이 보다 자연스럽게 대화를 이해하고 복잡한 작업을 스스로 수행하도록 돕습니다.

💻 Developers
Xing4는 sparse activation(희소 활성화)과 효율적인 attention 설계를 통해 모델 용량을 늘리면서도 연산량을 절감하도록 설계되었습니다. 하지만 285B 파라미터 규모를 8,192개의 Ascend 910C 카드로 학습하는 데는 높은 전력 소비와 복잡한 분산 관리가 필요하므로, 실제 서비스에 적용할 때는 추론 속도와 비용을 고려한 최적화가 필수합니다.

🔬 Researchers
Xing4의 sparse activation과 hybrid sharding이 실제 장기 추론 정확도에 미치는 영향을 정량화하는 연구가 아직 부족합니다. 또한 TeleGym의 비동기 실행과 부분 롤아웃이 다양한 에이전트 환경에서 정책 안정성에 어떤 영향을 주는지 체계적인 벤치마크가 필요합니다.
