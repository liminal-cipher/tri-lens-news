## 2. Unkernel: Real Linux kernel, compiled to WebAssembly

원문: <https://unkernel.dev> (Hacker News)

🌐 Everyone
Unkernel이라는 기술이 Linux kernel을 WebAssembly 형태로 변환해 브라우저 안에서도 실제 리눅스 환경을 실행할 수 있게 만들었습니다. 그 결과 일반 사용자도 별도의 가상 머신을 설치하지 않고 웹 페이지에서 바로 리눅스 프로그램을 사용할 수 있습니다.

💻 Developers
Unkernel은 기존 Linux kernel을 WebAssembly 바이너리로 컴파일해 sandbox 환경인 브라우저에서 직접 구동합니다. 이 과정은 LLVM 기반 백엔드와 syscalls 에뮬레이션을 필요로 하며, 실행 시 메모리 사용량과 초기 로드 시간이 일반 WASM 애플리케이션보다 증가하는 대가가 있습니다.

🔬 Researchers
Unkernel은 완전한 시스템 콜 호환성을 목표로 하지만, 아직 일부 장치 드라이버와 실시간 스케줄링 기능이 WebAssembly 제약으로 정확히 재현되지 않고 있습니다. 이를 해결하려면 WASM 표준에 새로운 privileged instruction 지원이나 커널 레벨 에뮬레이션 레이어의 정교한 최적화 연구가 필요합니다.

## 3. Stable Gated DeltaNet-2: Understanding and Mitigating Recurrent State Instability

원문: <https://arxiv.org/abs/2611.34051> (Hugging Face Papers)

🌐 Everyone
긴 텍스트를 처리할 때 상태가 급격히 커져 학습이 멈추는 문제가 있었지만, 새로운 방법으로 이를 안정화시켰습니다. 덕분에 아주 긴 문서 요약이나 장기 기억이 필요한 서비스가 더 신뢰성 있게 동작합니다.

💻 Developers
우리는 이 개선된 모델을 Stable Gated DeltaNet-2 (Stable GDN-2)라 명명했습니다. 여기서는 symmetric erasure(지우기 연산을 양쪽 방향에서 동일하게 적용)와 decay‑regulated residual writing(쓰기 강도를 점진적으로 감소시키는 방식)을 결합해 비정상적인 상태 성장 없이도 청크 단위 병렬 처리를 유지합니다.

🔬 Researchers
Stable GDN-2는 상태 성장에 대해 O(T) 상한(토큰 수에 비례하는 선형 제한)을 이론적으로 보장하지만, 다양한 토큰 분포에서 실제 성장 패턴은 아직 완전히 파악되지 않았습니다. 또한, 쓰기 유연성을 유지하면서 안정성을 더욱 높일 수 있는 최적의 설계가 무엇인지 탐구가 필요합니다.
