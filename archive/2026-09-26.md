## 3. Training Object Permanence in World Models

원문: <https://arxiv.org/abs/2609.28654> (Hugging Face Papers)

🌐 Everyone
화면에서 물체가 벽이나 상자 뒤로 가려져도 사라지지 않고 그대로 존재한다는 기본 물리 법칙을 인공지능 영상 생성 기술에 학습시켰습니다.
가려진 물체의 위치와 움직임을 잊지 않고 기억하게 하면서, 현실 세계처럼 어색함 없이 자연스럽게 이어지는 영상을 만들어냅니다.

💻 Developers
Blender로 합성한 150만 개 규모의 WROP 데이터셋으로 16B 파라미터 world model인 PWM-WROP를 학습시켜 object permanence(물체 영속성: 눈에 보이지 않아도 물체가 계속 존재함을 아는 인지 능력)를 구현합니다.
AWS Trainium2 기반의 native-PyTorch 학습 스택과 가중치가 공개되어 활용할 수 있지만, continuation model 특성상 생성하는 프레임 수가 길어질수록 VRAM 소모량과 추론 시간이 크게 늘어납니다.

🔬 Researchers
Blender 렌더링으로 생성된 정제된 데이터 환경에서 확보한 능력이 복잡한 현실 세계 비디오 영역으로 얼마나 잘 일반화되는지는 입증이 더 필요합니다.
continuation model이 기록한 우수한 점수가 실제 물리 법칙의 정교한 이해에서 비롯된 것인지 평가 문항의 절차적 특성에 오버피팅된 결과인지 변수를 다각도로 분리하는 연구가 요구됩니다.
